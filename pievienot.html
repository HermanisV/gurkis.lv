Pievienot ko jaunu

Šeit ar savu GitHub kontu vari iesniegt vai rediģēt pieprasījumus lapai — jaunu recepti (no saites vai piezīmēm) vai jaunu lapas funkciju. AI aģents šos pieprasījumus nolasa, ievieš un pēc izpildes automātiski aizver.

1. Izveidot jaunu pieprasījumu

Izvēlies pieprasījuma veidu un aizpildi laukus — nospiežot pogu, atvērsies jau sagatavots GitHub Issue tavā kontā.

📷 Attēli: Pēc pogas "Iesniegt pieprasījumu GitHub" nospiešanas atvērtajā GitHub pieteikuma logā vari ērti iekopēt (Ctrl+V) vai ievilkt ēdiena un starpsoļu fotogrāfijas.
