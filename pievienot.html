Pievienot ko jaunu

Šeit ar savu GitHub kontu vari iesniegt vai rediģēt pieprasījumus lapai — jaunu recepti (no saites vai piezīmēm), izmaiņas esošā receptē vai jaunu lapas funkciju. AI aģents šos pieprasījumus nolasa, ievieš un pēc izpildes automātiski aizver.

1. Izveidot jaunu pieprasījumu

Izvēlies pieprasījuma veidu un aizpildi laukus — nospiežot pogu, atvērsies jau sagatavots GitHub Issue tavā kontā.
