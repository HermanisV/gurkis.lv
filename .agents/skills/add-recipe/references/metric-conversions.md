# Metric & Ingredient Weight Conversion Reference

Use this reference whenever converting volumetric (`cups`, `tbsp`, `tsp`, `glāze`) or imperial (`oz`, `lb`, `fl oz`, `°F`, `inch`) measurements into metric weight (`g`) and volume (`ml`).

---

## 1. Base Unit Conversions

| Original Unit | Metric Equivalent | Kitchen Rounded |
| :--- | :--- | :--- |
| `1 US cup` (šķidrums) | `236.6 ml` | **`240 ml`** |
| `1 metric cup` / `1 glāze` | `250 ml` / `200 ml` | **`240 ml`** (US) / **`200 ml`** (LV glāze) |
| `1 tbsp` (ēdamkarote, `ēk`) | `14.8 ml` | **`15 ml`** |
| `1 tsp` (tējkarote, `tk`) | `4.9 ml` | **`5 ml`** |
| `1 fl oz` (šķidrā unce) | `29.6 ml` | **`30 ml`** |
| `1 oz` (unce, svars) | `28.35 g` | **`28 g`** (vai **`30 g`**) |
| `1 lb` (mārciņa) | `453.6 g` | **`450 g`** |
| `1 stick of butter` (US) | `113.4 g` (½ cup) | **`115 g`** |
| `1 inch` (colla) | `2.54 cm` | **`2.5 cm`** |

## 2. Dry & Solid Ingredients: Volume → Grams (`g`)

Always convert volumetric amounts of these ingredients to **grams (`g`)**:

### Milti, Ciete un Kakao (Flours, Starches & Cocoa)
| Ingredient (EN → LV) | 1 US Cup (`240 ml`) | 1 tbsp (`1 ēk`) | 1 tsp (`1 tk`) |
| :--- | :--- | :--- | :--- |
| All-purpose / Bread / Whole wheat flour (`kviešu milti`) | **`120 g`** | `8 g` | `3 g` |
| Cake / Pastry flour (`konditorejas kviešu milti`) | **`115 g`** | `7 g` | `2.5 g` |
| Rye flour (`rudzu milti`) | **`105 g`** | `7 g` | `2 g` |
| Almond flour (`mandeļu milti`) | **`95 g`** | `6 g` | `2 g` |
| Cornstarch / Potato starch (`kukurūzas / kartupeļu ciete`) | **`120 g`** | `8 g` | `3 g` |
| Unsweetened cocoa powder (`nesaldināts kakao pulveris`) | **`95 g`** | `6 g` | `2 g` |

### Dārzeņi un Augļi (Produce Weight Approximations)
When a recipe specifies volumetric produce (e.g., "1 cup chopped onion") or vague counts, include approximate weight in grams:
- `1 vidējs sīpols (vai 1 cup sasmalcināts)` → **`150 g` (1 vidējs) sīpols**
- `1 vidējs burkāns` → **`100 g` (1 vidējs) burkāns**
- `1 vidējs kartupelis` → **`150 g` kartupelis**
- `1 vidēja paprika` → **`150 g` (1 gab.) saldā paprika**
- `1 cup svaigi spināti` → **`30 g` svaigi spināti**
- `1 cup ogas (mellenes, zemenes, avenes)` → **`150 g` ogas**
- `1 vidējs banāns (nomizots)` → **`120 g` (1 vidējs) banāns**

## 3. Oven Temperature Conversions (`°F` → `°C`)

| Fahrenheit (`°F`) | Exact Celsius | Kitchen Standard (`°C`) |
| :--- | :--- | :--- |
| `250 °F` | `121 °C` | **`120 °C`** |
| `300 °F` | `149 °C` | **`150 °C`** |
| `325 °F` | `163 °C` | **`160 °C` – `165 °C`** |
| `350 °F` | `177 °C` | **`180 °C`** |
| `375 °F` | `191 °C` | **`190 °C`** |
| `400 °F` | `204 °C` | **`200 °C`** |
| `425 °F` | `218 °C` | **`220 °C`** |
| `450 °F` | `232 °C` | **`230 °C`** |
| `475 °F` | `246 °C` | **`245 °C` – `250 °C`** |
| `500 °F` | `260 °C` | **`260 °C`** |
